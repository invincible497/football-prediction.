# PredicKick | Football Match Outcome Prediction System

A complete, production-grade Football Match Outcome Prediction System built using Python, Scikit-learn, Pandas, NumPy, SQLite, and Streamlit.

## 🌟 Key Features

1. **Intelligent Match Prediction Engine**:
   - Probabilistic predictions for three outcomes:
     - **Home Team Win (1)**
     - **Draw (X)**
     - **Away Team Win (2)**
   - Strict probability calibration ensuring $\sum P = 100.0\%$.
   - Confidence scoring based on margin over uniform random chance baseline ($33.3\%$).
   - Analytical factor explanations detailing form momentum, venue win rates, net goal efficiency, and head-to-head dynamics.

2. **Zero Future Data Leakage**:
   - Strictly chronological feature calculation using only matches played **before** the fixture date being predicted.
   - Chronological train/test split (no random shuffling of temporal data).

3. **Machine Learning Benchmarking**:
   - Compares three competitive classification algorithms:
     1. **Logistic Regression** (Multinomial with balanced class weights)
     2. **Random Forest Classifier** (Ensemble of decision trees with depth regularization)
     3. **Gradient Boosting Classifier** (Iterative boosted decision trees)
   - Comprehensive multi-class evaluation:
     - Multi-class Accuracy
     - Weighted & Macro F1-Score
     - Weighted & Macro Precision
     - Weighted & Macro Recall
     - Multi-class Log Loss ($\text{log\_loss}$)
     - Multi-class Brier Score ($\frac{1}{N} \sum_{i} \sum_{k} (p_{ik} - y_{ik})^2$)
     - Confusion Matrix heatmaps
     - Feature importance rankings

4. **Engineered Match Features**:
   - Rolling 5-match points accumulated ($3$ for Win, $1$ for Draw, $0$ for Loss)
   - Rolling goals scored and goals conceded averages
   - Venue-specific win rates (Home team at home, Away team away)
   - Overall cumulative win percentages
   - League-wide home advantage factor
   - Head-to-Head (H2H) historical encounter record
   - Recovery days / schedule fatigue
   - Goal differential and points differentials

5. **SQLite Persistent Database**:
   - Stores `leagues`, `teams`, `matches`, and `predictions` history.
   - Interactive verification tool to log actual match results and track live prediction accuracy over time.

6. **Interactive Streamlit Web Dashboard**:
   - **📊 Dashboard**: High-level KPIs, outcome distribution pie charts, recent activity stream.
   - **⚽ Match Predictor**: Dynamic team pickers by league, match date selector, animated probability displays, and factor breakdown.
   - **📈 Team Analysis**: Deep-dive team cards, recent form streaks (🟢 W, 🟡 D, 🔴 L), and H2H explorer.
   - **🤖 Model Performance**: Cross-model comparison matrix, confusion matrix heatmaps, and feature importance charts.
   - **📜 Prediction History**: Full audit trail, result verification, and CSV export.
   - **⚙️ Data & Model Settings**: One-click dataset resync and model retraining.

## 🚀 Running the Application

### 1. Launch the Streamlit Dashboard
```bash
streamlit run app.py
```
Or specify a custom port:
```bash
streamlit run app.py --server.port 8501
```

### 2. Run the Verification & Integration Tests
```bash
python test_pipeline.py
```
